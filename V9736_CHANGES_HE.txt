Ariella Tours 9.7.36
- הגנת הצרכן + שינוי/ביטול חזרו למרכז החלק העליון של אזור המחיר.
- המלל הוזז מעט למעלה באמצעות transform בלבד, בלי להגדיל את גובה הדיל.
- נוקה קוד ישן של לשונית "הדילים לחופשות שלי" שעלול היה לשבש JavaScript.
- כל מסנני הדילים נבנו מחדש בצורה עצמאית ועמידה:
  מוצא, יעד, חודש, מחיר מקסימלי, סוג טיסה, כבודה, שעת יציאה,
  משך חופשה, חברת תעופה, הגנת הצרכן ושינוי/ביטול.
- הסתרת כרטיסים נעשית עם class + display:none!important כדי שלא תבוטל ע"י CSS של הכרטיס.
- נוסף מסר כשאין דילים שמתאימים למסננים.
- כפתור "נקה" מאפס את כל המסננים ומחזיר את כל הדילים.
- כל שינויי 9.7.35 נשמרו.

## איך מבצעים משימה
1. שקד שולחת: מה לבדוק, על איזה ענף (בדרך כלל main או ענף של בקשת מיזוג), ומה התוצאה הצפויה. חסר משהו מהותי — שאל אותה לפני שמתחילים.
2. `git fetch origin <ענף>` ואז `git checkout -B tom/<מזהה-משימה> origin/<ענף>`.
3. אם חסרות חבילות: `pip install -q --ignore-installed blinker -r requirements.txt pyflakes`.
4. בדוק: `python3 qa/run_qa.py` (אם קיים), והבדיקות הספציפיות שהתבקשו — זרימות, עמודים, מפענחי שיחה, מקרי קצה.
5. אם התבקשת להוסיף מקרי בדיקה — רק בתוך `qa/` (למשל `qa/cases.json`), commit בעברית ו-`git push -u origin tom/<מזהה-משימה>`.
6. החזר לשקד `send_message` עם: מה נבדק, ✅/❌ לכל בדיקה, לכל כשל — קובץ:שורה, מה קורה ואיך משחזרים, חומרה (🔴/🟠/🟡), ושם הענף אם הוספת מקרי בדיקה.

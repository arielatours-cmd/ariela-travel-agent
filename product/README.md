# תהליך המוצר של אריאלה

התיקייה הזו היא "השולחן" של **אופק** — סוכנת המוצר של אריאלה (`.claude/agents/ofek.md`).

**צעד יומי:** אופק רצה לבד כל בוקר ב-08:52 (שעון ישראל) ומקדמת דבר אחד: רעיון חדש, תוכנית, או משימת פיתוח לתוכנית שאושרה.
היומן נשמר ב-`daily/`, בענף `ofek`. מדברים איתה בסשן "אופק" באפליקציית Claude.

## איך זה עובד
1. **רעיונות** — נאספים ב-`IDEAS.md` עם עדיפות.
2. **תוכנית** — רעיון שנבחר הופך לקובץ ב-`plans/` (לפי `plans/_TEMPLATE.md`) בסטטוס `ממתין לאישור`.
3. **אישור** — בעלת העסק כותבת בשיחה עם Claude Code: "מאשרת תוכנית 001" (אפשר "רק שלב 1", או עם הערות).
4. **משימת פיתוח** — הסוכנת כותבת הוראות מדויקות ב-`dev-tasks/`, ואחרי אישור להתחיל — הפיתוח מתבצע, נבדק ונדחף לענף.

## פקודות שימושיות בשיחה
- `/ariella-pm תני 5 רעיונות חדשים לשימור לקוחות`
- `/ariella-pm תכיני תוכנית על רדאר אישי`
- `/ariella-pm סטטוס`
- `/ariella-pm מאשרת תוכנית 001 רק שלב 1`

## סטטוסים
ממתין לאישור → מאושר → בפיתוח → פותח — ממתין ל-QA → שוחרר | נדחה

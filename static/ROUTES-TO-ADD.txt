כדי שהקישור "קצת עלינו" יעבוד, ודאי שבקובץ Flask הראשי קיימים הייבוא והנתיבים הבאים:

from flask import render_template

@app.get("/")
def home():
    return render_template("home.html")

@app.get("/about")
def about():
    return render_template("about.html")

חשוב:
1. הקבצים home.html ו-about.html צריכים להיות בתוך תיקיית templates.
2. אם כבר קיימת פונקציה בשם home שמחזירה JSON, החליפי את התוכן שלה ב-render_template("home.html").
3. אין להוסיף פונקציה נוספת בשם home או about אם כבר קיימת – רק לעדכן את הקיימת.

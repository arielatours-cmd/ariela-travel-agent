# כספים — השולחן של יוסף

**יוסף** הוא סמנכ"ל הכספים של אריאלה (`.claude/agents/yosef.md`).
כל יום ראשון בבוקר הוא כותב דוח תקציב ב-`reports/`. מדברים איתו בסשן "יוסף" באפליקציית Claude.

## הקבצים
| קובץ | מה יש בו | מי מעדכן |
|---|---|---|
| `expenses.csv` | ספר ההוצאות: כל חיוב בפועל ועלויות קבועות | בעלת העסק מוסרת, יוסף רושם |
| `assumptions.json` | הנחות הסימולציה: מחירי חבילות, מכסות, תרחישי לקוחות | יוסף, רק עם נתונים מאומתים |
| `simulate_costs.py` | סימולציית עלויות סריקה חודשית לפי תרחישים | — |
| `reports/` | דוחות התקציב השבועיים | יוסף |

## איך מעבירים לו נתונים
כותבים לו בסשן, למשל:
- "Render עולה 7 דולר בחודש, חויב ב-1 לחודש"
- "שילמנו לאנתרופיק 23 דולר בספטמבר"
- מדביקים ייצוא מטבלת scan_runs או payments מלוח הבקרה (`/admin`)

## הרצה ידנית
`python3 finance/simulate_costs.py`
